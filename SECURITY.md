# Security Policy

## Supported Versions

Only the latest version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Kenya Quest, please report it responsibly:

1. **Do not** file a public issue or discuss it in public chat.
2. Email the repository maintainer with details, reproduction steps, and potential impact.
3. You should receive an acknowledgment within 48 hours.
4. We will coordinate a fix and release before any public disclosure.

Thank you for helping keep Kenya Quest secure for all users!
